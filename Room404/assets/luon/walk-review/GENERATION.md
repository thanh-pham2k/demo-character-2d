# Walking atlas review

Built-in OpenAI image generation produced this single 4 × 2 sheet using `walk-v3/sheet.png` as the character reference. Prompt: same character in four walk-cycle phases, alternating foreground leg and arm, with the first row without and the second row with a blue backpack.

The generated result repeats the same extended stride in columns 1 and 3, so it does not satisfy the requested alternating gait. It is retained as a rejected review source, not sliced or wired into the preview. The source is 1774 × 887 px; the intended four-column, two-row grid is not production-ready. No pivot or PPU applies to this rejected source.
