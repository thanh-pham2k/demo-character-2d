# Climbing in socks

Built-in OpenAI image generation: one 2 × 2 transparent batch, reference `actions-v3/climb_0.png`. Prompt requested the same boy climbing viewed from behind with white socks on both feet, without shoes or ladder. `sheet.png` is 1278 × 1230. `slice.py` records crop rectangles for four frames, none of which touches a cell edge. `climb_0`–`3` are PNG and traced SVG, bottom-center pivot on a 300 × 460 normalized canvas; SVG viewBox 150 × 230. Pixels per unit is not applicable to web. The generated poses vary only slightly in leg position, so the climb cycle is approximate.
